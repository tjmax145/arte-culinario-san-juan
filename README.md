# Arte Culinario — San Juan 🇦🇷

Sitio web dedicado al arte culinario desde San Juan, Argentina.

## Características

- Página pública de recetas.
- Buscador.
- Página individual para cada receta.
- Panel privado de administración.
- Crear recetas.
- Editar recetas.
- Eliminar recetas.
- Subir fotografías.
- Diseño adaptable para celulares y computadoras.
